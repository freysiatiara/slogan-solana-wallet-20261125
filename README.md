## The entry

> Ask your wallet. It answers in Solana.

The slogan turns the wallet agent into a conversation: you ask, it answers — in Solana. Short, plain, and honest about what the agent does.

## How it works

Run `python3 main.py`. It validates the slogan (one line, 1–140 characters, at most 20 words, no leading or trailing whitespace) and writes it to `/output/entry.txt` with mode 0644.
